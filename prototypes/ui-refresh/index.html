LP Sketch / six UI directions

Static single-page prototypes for a UI refresh. Nothing is wired up beyond hover states and load motion. Each one shows the same project, the same roof plan and the same tool set, so the comparison is about layout, type, color and density. Open a card to see it full size.

DIRECTION 01

Nightshift

Dark studio chrome so the white plan is the brightest thing on screen. Left tool palette, right inspector that follows the tool or selection, amber as the single accent.
palette + inspectordarkManrope · JetBrains Mono
DIRECTION 02

Vellum

The app as a drawing sheet. Title-block strip on top, a single ribbon of tool clusters, CAD-style status strip below, ink on warm paper with a faint grain.
ribbon + status striplight · paperArchivo · DM Mono
DIRECTION 03

Hover

Full-bleed canvas with floating glass pills. Tool dock on top with pop-out groups, material rail on the left, context strip at the bottom. Built for the iPad first.
floating dockglass on lightInstrument Sans · Geist Mono
DIRECTION 04

Tempered

The current sidebar, kept and tuned. A sticky stroke widget replaces the Material panel, tabs replace the long scroll, and the properties bar becomes a calmer context bar.
sidebar refinementlight · coolHanken Grotesk · IBM Plex Mono
DIRECTION 05

Hi-Vis

Field-first. Black rules, white panels and safety yellow for whatever is active. Bottom tool tray with big targets, material chips on the left, layers on the right.
bottom trayhigh contrastAtkinson Hyperlegible · Red Hat Mono
DIRECTION 06

Ledger

Editorial and quiet. A serif project header with a title-block meta table, a labelled tool rail, and a right-hand specification panel with numbered sections and a component catalog.
rail + spec panellight · creamFraunces · Familjen Grotesk
How to read these. Two things vary at once: the shell (where tools live) and the skin (type, color, texture). Any shell can wear any skin. If a layout feels right but the mood is off, or the other way round, say so and the next round can cross them.
